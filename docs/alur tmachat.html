⚖️
Model yang Digunakan
cross-encoder/ms-marco-MiniLM-L-6-v2
via HuggingFace · dapat dijalankan lokal
Cara Kerja vs Bi-Encoder
Bi-encoder (Qdrant): embed query & doc terpisah → cosine similarity cepat tapi kasar
Cross-encoder: baca (query + doc) secara joint → skor relevansi lambat tapi akurat
Strategi top-k
Qdrant ambil top-20 kandidat kasar
Reranker seleksi jadi top-5 berkualitas tinggi
trade-off: +latency ~50-150ms · kualitas meningkat signifikan

Step 2 · LLM Thinking (Chain-of-Thought)
Model: gemini-1.5-pro
Teknik: Chain-of-Thought reasoning

LLM diminta berpikir dulu:
1. Apa fakta dari data?
2. Apa standar dari policy?
3. Apa gap antara keduanya?
4. Apa akar masalah / rekomendasi?

→ Thinking result dikirim ke Step 3
